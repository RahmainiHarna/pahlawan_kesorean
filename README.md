
# Cafe Kesorean

## Deskripsi Proyek
Cafe Kesorean merupakan aplikasi berbasis web yang dirancang untuk membantu proses operasional kafe, mulai dari pemesanan menu oleh pelanggan hingga pengelolaan transaksi dan pemantauan penjualan. Aplikasi ini memiliki beberapa jenis pengguna dengan hak akses yang berbeda, yaitu Owner, Admin, Kasir, dan Pelanggan. Setiap pengguna memiliki fitur yang disesuaikan dengan kebutuhan dan tanggung jawabnya.

## Tujuan Proyek
- Mempermudah proses pemesanan menu oleh pelanggan.
- Membantu pengelolaan menu dan kategori produk.
- Mendukung pencatatan transaksi dan pengeluaran.
- Mempermudah pemantauan aktivitas operasional serta penjualan kafe.

## Fitur Utama

### Pelanggan
- Melihat daftar menu.
- Memilih dan memesan menu.
- Mengelola keranjang belanja.
- Melakukan checkout dan pembayaran.

### Kasir
- Mengelola proses transaksi pelanggan.
- Memproses pembayaran tunai maupun QRIS.

### Admin
- Mengelola menu dan kategori.
- Mengelola promo.
- Memantau transaksi dan pengeluaran.

### Owner
- Memantau laporan penjualan.
- Melihat ringkasan transaksi.
- Memantau pengeluaran.
- Melihat aktivitas pengguna.
